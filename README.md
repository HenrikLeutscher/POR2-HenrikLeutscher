## Installation
Clone the Repo
```
git clone https://github.com/HenrikLeutscher/POR2-HenrikLeutscher.git
```
Navigate to the Project Folder
```
cd POR2-HenrikLeutscher
```
Install Dependencies
```
npm install
```
Run the application in browser
```
npm run dev
```
